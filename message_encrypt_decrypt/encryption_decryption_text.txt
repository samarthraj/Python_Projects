message is originally a string (human-readable text).
.encode("ascii") converts it into bytes where each character is represented using its ASCII binary equivalent.
Base64 takes those bytes and encodes them into another set of characters.
It does this by taking 6-bit chunks of binary data and mapping them to a set of 64 printable characters (A-Z, a-z, 0-9, +, /).
The goal of Base64 is to make binary data printable and safe for transmission (e.g., sending over email, URLs).
Base64-encoded data is not human-readable in bytes form.
.decode("ascii") converts it back to a string so it can be stored, displayed, or sent as text.
